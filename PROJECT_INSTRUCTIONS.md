# Project Instructions

This repository follows the developer workflow supplied for the Iron Condor to Ratio research project.

## Controls
1. Research is phase-based; each phase is developed on a separate Git branch.
2. The research plan changes only when the proposed plan changes.
3. Every research step updates status and records outcomes/errors.
4. Errors are logged in the repository.
5. README is updated with material status, results and links.
6. Data provenance, caching and reproducibility are documented.
7. Market backtests account for slippage, transaction costs, brokerage and applicable charges.
8. Workflows support automated execution and manual dispatch where applicable.
9. Tester validation is a gate before the developer advances to subsequent phases.
10. Final delivery includes a complete structured research manuscript and reproducibility supplements.

## Source-control note
The project requests preservation of every conversation and thinking process. Repository logs preserve user-visible decisions and summaries; hidden chain-of-thought is not stored.
